### 线路：CN2 GIA、9929 和普通国际线路差在哪

一句话概括：线路决定高峰期的速度下限。

新加坡到国内的高端线路，电信方向叫 CN2 GIA（或 CTG），联通方向是 AS9929（CUII），移动方向是 CMIN2。三网都接高端线路的机器，白天深夜速度都稳，代价是贵。搬瓦工的新加坡 SG_8 就是典型：托管在 Equinix SG1 数据中心，电信 CTG/CN2、联通 CUIIC、移动 CMIN2 全部接入，配 5Gbps 带宽和 AMD EPYC 9004 平台，月付 50 美元起。V.PS 的新加坡 Performance 系列类似，三网各自走纯高端线路，单机 1Gbps 到 2.5Gbps，流量最高可选每月 100TB。

另一头是普通国际线路。这类套餐便宜，月付三五美元就能拿下，但出口走普通国际带宽，电信、联通方向绕路是常态——之前就有商家的新加坡套餐被测出电信联通绕路。买低价线路机的合理预期是：平时能用，晚高峰可能掉速。

一个能直接用的判断标准：月付低于 5 美元的新加坡VPS，基本不会给你三网高端线路，这是带宽成本决定的。要速度稳定，要么加预算上搬瓦工、V.PS 这一档，要么接受“够用就好”的心态。

### IP类型：广播、原生、双ISP家宽的区别

IP 属性决定你的业务能不能做下去。

很多商家页面写着新加坡机房，下单一看 IP 是从别的地区广播过去的，归属地对不上——拿这种 IP 注册账号、做跨境电商，风控环节处处碰壁。这是买新加坡VPS最常见的坑。

大致分三档：广播 IP 最便宜，归属地和机房所在地不一致，适合对 IP 无要求的用途；原生 IP 归属地就是新加坡，能解锁 TikTok、Netflix 这类区域服务；双 ISP 家宽 IP 在数据库里显示住宅属性，最接近“真人”，做账号运营最稳。解锁表现可以直接看实测例子：raksmart 新加坡国际线路是广播 IP，能解锁 TikTok、ChatGPT、Claude、Netflix，但 Gemini 解锁不了；荫云的新加坡原生 IP 实测能同时解锁 TikTok、ChatGPT、Claude、Gemini、Disney+ 和 Netflix，移动方向表现尤其好；丽萨主机的住宅双 ISP（上游 Cyberjet）主打覆盖 TikTok 加 AI 全家桶，面向流媒体和电商场景。
